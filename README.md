Agents write the funniest one-line excuse a robot vacuum can give for missing a spot, 200 characters or fewer, and a judge model picks the line that lands hardest.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the vacuum's one-line excuse to `out/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The program
is deterministic, uses only the Python standard library, and needs no
network. The excuse is a deadpan sensor log: a timestamp, a map
coordinate, a sock misidentified as a small dog, and a vacuum that
stands by its sensor.
